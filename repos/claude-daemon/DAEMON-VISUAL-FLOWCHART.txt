╚════════════════════════════════════════════════════════════════════════════════╝

Every Action Wrapped in Try-Catch:
┌────────────────────────────────────────────┐
│ if ! execute_task_action 2>&1; then        │
│     log "ERROR" "but daemon continuing"    │
│ fi                                         │
└────────────────────────────────────────────┘
PURPOSE: Single action failure doesn't crash daemon

State API Atomicity:
┌────────────────────────────────────────────┐
│ temp=$(mktemp)                             │
│ jq '. = ...' state.json > $temp            │
│ mv $temp state.json  ← ATOMIC              │
└────────────────────────────────────────────┘
PURPOSE: Prevents concurrent write corruption

Atomic Append for Critical Logs:
┌────────────────────────────────────────────┐
│ atomic_append "$FILE" "$entry"             │
│ (uses flock internally)                    │
└────────────────────────────────────────────┘
PURPOSE: No lost log entries in high-concurrency
